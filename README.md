# پیکره متنی و ساختاریافته فهارس (مأخذ فنخا - ۳۴ جلد)
### Fahares (Fankha) Manuscript Corpus & Structured Dataset (34 Volumes)

این مخزن دربرگیرنده پیکره متنی استاندارد، ممیزی‌شده و پالایش‌یافته، همراه با خط لوله استخراج ساختاریافته و داده‌های JSON دوره ۳۴ جلدی **«فهرستگان نسخه‌های خطی ایران (فنخا)»** به کوشش **مصطفی درایتی** است که به عنوان نخستین و جامع‌ترین مأخذ مرجع در سامانه متافهرستگان [فهارس (Fahares)](https://github.com/fahares/fahares) مستقر گردیده است.

## ۲. تازه‌های نگارش v1.1.1 (Release Highlights)

* **اصلاح ساختاری شکست سطر در ۱,۴۸۹ رکورد نسخه:** در متون منبع فنخا، به دلیل عدم شکستگی سطر پس از شماره نسخه، اطلاعات کالبدشناسی (کاتب، تاریخ، خط، ابعاد، اوراق و استناد فهرست) در شماره نسخه ادغام شده بودند. در نگارش v1.1.1 تمامی این ۱,۴۸۹ سطر با دقت اصلاح و تفکیک شده و فراداده‌های غنی آن‌ها استخراج شدند.
* **پارسر چندپردازنده‌ای موازی (Multi-Core Parser):** اسکریپت `parse_all_volumes.py` به قابلیت مهار موازی هسته‌های CPU با تشخیص پویا مجهز شد که زمان تولید خروجی‌های کل ۳۴ جلد را از ۶ دقیقه به ۱۶۴ ثانیه کاهش داد.
* **افزودن ابزار ممیزی سلامت داده‌ها:** اسکریپت `audit_shelfmark_leaks.py` برای پایش و ممیزی دائمی ساختار متون و شماره نسخه‌ها به مخزن افزوده شد.

## ۳. ساختار مخزن (Repository Structure)

```text
fahares-corpus/
├── text/                         # ۳۴ فایل متنی پیراسته، ممیزی‌شده و استاندارد
│   ├── fahares_vol_01.txt
│   └── ...
│   └── fahares_vol_34.txt
├── scripts/                      # خط لوله استخراج و ابزارهای تکرارپذیری علمی
│   ├── fankha_parser.py          # موتور پارسر تحلیلی تک‌جلدی (Zero-dependency Python)
│   ├── parse_all_volumes.py      # اسکریپت اجرای موازی چندپردازنده‌ای روی ۳۴ جلد در ۱۶۴ ثانیه
│   ├── audit_shelfmark_leaks.py  # ابزار ممیزی و پایش یکپارچگی شماره نسخه‌ها و بافت کالبدشناسی
│   ├── download_json.sh          # اسکریپت دانلود مستقیم بسته آماده JSON از ریلیزهای گیتهاب
│   └── build_full_text.sh        # اسکریپت تجمیع ۳۴ جلد در فایل یکپارچه fankha-full.txt
├── json/                         # محل قرارگیری ۳۴ فایل JSON (مستثنی از گیت جهت سبکی مخزن)
└── README.md                     # شناسنامه، آمار کلان و مستندات فنی
```

## ۴. نحوه دریافت داده‌های ساختاریافته (JSON Dataset)

به منظور سبک نگاه داشتن مخزن گیت و تسهیل عملیات Clone، فایل‌های ۱.۱ گیگابایتی JSON در تاریخچه گیت کامیت نشده‌اند. شما می‌توانید به دو روش بسیار ساده آن‌ها را دریافت یا تولید کنید:

### روش ۱: دانلود مستقیم پکیج رسمی آماده (پیشنهادی)
کل ۳۴ فایل JSON در قالب یک فایل فشرده ۱۰۴ مگابایتی در [بخش Releases گیتهاب](https://github.com/fahares/fahares-corpus/releases/tag/v1.1.1) در دسترس است. برای دانلود و استخراج خودکار:

```bash
chmod +x scripts/download_json.sh
./scripts/download_json.sh
```

یا دانلود مستقیم با `curl`:
```bash
mkdir -p json
curl -L https://github.com/fahares/fahares-corpus/releases/download/v1.1.1/fahares_json_v1.1.1.tar.gz | tar -xz -C json/
```

### روش ۲: بیلد محلی از روی فایل‌های متنی با پایتون
با توجه به سرعت فوق‌العاده بالای موتور پارسر چندپردازنده‌ای، می‌توانید تمام ۳۴ فایل JSON را مستقیماً از روی فایل‌های متنی موجود در همین مخزن ظرف کمتر از ۲.۸ دقیقه تولید کنید:

```bash
python3 scripts/parse_all_volumes.py
```
