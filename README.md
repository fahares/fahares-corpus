# پیکره متنی و ساختاریافته فهرستگان نسخه‌های خطی ایران (فنخا)
### Fahares (Fankha) Manuscript Corpus & Structured Dataset (34 Volumes)

این مخزن دربرگیرنده پیکره متنی استاندارد، ممیزی‌شده و پالایش‌یافته، همراه با خط لوله استخراج ساختاریافته و داده‌های JSON دوره ۳۴ جلدی **«فهرستگان نسخه‌های خطی ایران (فنخا)»** به کوشش **مصطفی درایتی** است.

## ۲. ساختار مخزن (Repository Structure)

```text
fahares-corpus/
├── text/                         # ۳۴ فایل متنی پیراسته، ممیزی‌شده و استاندارد
│   ├── fahares_vol_01.txt
│   └── ...
│   └── fahares_vol_34.txt
├── scripts/                      # خط لوله استخراج و ابزارهای تکرارپذیری علمی
│   ├── fankha_parser.py          # موتور پارسر تحلیلی تک‌جلدی (Zero-dependency Python)
│   ├── parse_all_volumes.py      # اسکریپت اجرای دسته‌ای روی ۳۴ جلد در کمتر از ۳.۵ دقیقه
│   ├── download_json.sh          # اسکریپت دانلود مستقیم بسته آماده JSON از ریلیزهای گیتهاب
│   └── build_full_text.sh        # اسکریپت تجمیع ۳۴ جلد در فایل یکپارچه fankha-full.txt
├── json/                         # محل قرارگیری ۳۴ فایل JSON (مستثنی از گیت جهت سبکی مخزن)
└── README.md                     # شناسنامه، آمار کلان و مستندات فنی
```

## ۳. نحوه دریافت داده‌های ساختاریافته (JSON Dataset)

به منظور سبک نگاه داشتن مخزن گیت و تسهیل عملیات Clone، فایل‌های ۱.۱ گیگابایتی JSON در تاریخچه گیت کامیت نشده‌اند. شما می‌توانید به دو روش بسیار ساده آن‌ها را دریافت یا تولید کنید:

### روش ۱: دانلود مستقیم پکیج رسمی آماده (پیشنهادی)
کل ۳۴ فایل JSON در قالب یک فایل فشرده ۹۸ مگابایتی در [بخش Releases گیتهاب](https://github.com/fahares/fahares-corpus/releases/tag/v1.0.0) در دسترس است. برای دانلود و استخراج خودکار:

```bash
chmod +x scripts/download_json.sh
./scripts/download_json.sh
```

یا دانلود مستقیم با `curl`:
```bash
mkdir -p json
curl -L https://github.com/fahares/fahares-corpus/releases/download/v1.0.0/fahares_json_v1.0.0.tar.gz | tar -xz -C json/
```

### روش ۲: بیلد محلی از روی فایل‌های متنی با پایتون
با توجه به سرعت فوق‌العاده بالای موتور پارسر، می‌توانید تمام ۳۴ فایل JSON را مستقیماً از روی فایل‌های متنی موجود در همین مخزن ظرف حدود ۳ دقیقه تولید کنید:

```bash
python3 scripts/parse_all_volumes.py
```
